# Restaurant artwork

The game bundles three transparent PNG atlases. No remote runtime assets are required.

| Asset | Grid | Contents |
| --- | --- | --- |
| `public/art/characters.png` | 4 × 4 | Chef front/back walks, customer walk, waiter walk |
| `public/art/diners.png` | 4 × 4 | Four diners with four walk frames each |
| `public/art/restaurant.png` | 4 × 3 | Tables, chairs, appliances, counter, plants, tree, produce, prepared and dirty dishes |

The built-in image-generation tool was used; no CLI/API fallback. Source alpha is preserved. `src/art.ts` uses explicit rectangles around complete silhouettes, including artwork crossing nominal grid boundaries. Character frames share a reference height per walk cycle and a body-based ground anchor. All sprite drawing uses a single uniform scale, including width-constrained furniture, so the source proportions are preserved. The original atlas is sampled directly. The renderer sizes its canvas backing store to the displayed size and device pixel ratio, then draws source sprites directly at that resolution with high-quality sampling. Shared logical floor coordinates keep camera movement and hit targets independent of display density. Furniture, people and dishes share depth ordering.

## Character prompt

Create a production game CHARACTER SPRITE SHEET for a cozy isometric restaurant pixel-art game. Transparent background. Exact 4 columns by 4 rows evenly spaced grid, 16 equal square cells. No text no grid lines. Each cell contains ONE whole character centered with feet at the same baseline, generous empty padding. Crisp hand-placed pixel art aesthetic, rich warm palette, dark colored outlines, detailed expressive faces, appealing proportions with large heads, 32-bit cozy farming RPG quality. Camera elevated 30 degrees, three-quarter isometric character view. Rows 1 and 2: the SAME young chef in cream toque, ivory shirt, sage green apron, brown shoes, warm brown hair. Row 1 facing southeast/front-right, four distinct walk-cycle frames (left step, contact, right step, contact). Row 2 same chef facing northwest/back-left, four walk cycle frames. Row 3: SAME young customer with auburn hair, coral jacket, cream blouse, dark navy pants, facing southeast, four walk frames. Row 4 SAME waiter with dark curly hair, blue shirt, ochre apron, carrying a small empty serving tray, facing southeast, four walk frames. Consistent anatomy, scale, lighting upper left, pixel density and baseline across all 16 cells. Render each figure about 55% cell width and 75% cell height. Actual usable sprite assets, not a mockup or scene. No ground, no shadow outside each character, no scenery.
